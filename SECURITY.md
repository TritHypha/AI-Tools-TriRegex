# Security policy

## Reporting a vulnerability

Please report suspected security issues privately to hello@trithypha.dev. Do
not open a public issue or disclose technical details publicly before
coordination with the project owner.

Include the affected version, a minimal input or pattern, the observed impact,
and clear reproduction steps. Remove credentials, tokens, private keys,
customer data, and other secrets before sending the report.

## Supported versions

The supported version is the latest released minor line. Reports against older
versions are still useful, but a fix may require reproducing the issue against
the current released line first.

## Coordinated disclosure

The project will acknowledge a report, assess reproducibility and impact, and
coordinate a disclosure timeline with the reporter. Do not publish a proof of
concept, affected inputs, or fix details until that coordination is complete.
